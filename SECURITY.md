# Security policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead: go to the
[Security tab](https://github.com/castroaj/date-aware-map-cache/security) and choose
**Report a vulnerability**.

Include the affected version, a description of the problem and, if you can, a minimal
reproduction. You can expect an acknowledgement within a week.

## Supported versions

Only the latest release line receives fixes.

## Scope

Chronomap trusts its datastore (see the checksum note in `GLOSSARY.md`): it is not a
defence against a hostile version source. Reports about the build, the dependencies it
pulls in, or how it handles malformed input are in scope.
